# 时间规划指令（4个指令）

用于时间管理、任务规划和目标跟踪的四个指令。

---

## 倒计时（deadline）

翻牌式倒计时器，适合项目截止、活动开始等场景。

::::tabs
tab: 演示效果

:::deadline{date="2026-12-31T23:59:59" title="新年倒计时" description="距离2027年还有"}
:::

已经过了截止时间，会显示 `expiredText`：

:::deadline{date="2025-01-01" title="早鸟报名" description="名额有限" expiredText="报名已结束" showSeconds="false"}
:::

tab: 示例代码

````markdown
:::deadline{date="2026-12-31T23:59:59" title="新年倒计时" description="距离2027年还有"}
:::

:::deadline{date="2025-01-01" title="早鸟报名" description="名额有限" expiredText="报名已结束" showSeconds="false"}
:::
````

- `date` — 目标日期时间，格式 `YYYY-MM-DDTHH:MM:SS`
- `title` — 倒计时标题
- `description` — 倒计时说明文字
- `showSeconds` — 是否显示秒，默认 `true`
- `expiredText` — 倒计时结束后的文字，默认「已截止」

## 日历（calendar）

macOS 风格日历，自动显示农历、二十四节气、法定节假日和调休，也可以写入自己的日程。支持前后切换月份和回到今天。

::::tabs
tab: 演示效果

:::calendar{month="2026-05"}

| date | type | content | color | link |
| ---- | ---- | ------- | ----- | ---- |
| 05-01 | 假期 | 五一出游 | red | |
| 05-12 | 工作 | 项目评审 | | |
| 05-20 | 生活 | 朋友聚会 | blue | |
| 05-25 | 项目 | Vergil v1.0 发布 | green | https://github.com/vergil-astro/vergil-astro-theme |

:::

tab: 示例代码

````markdown
:::calendar{month="2026-05"}

| date | type | content | color | link |
| ---- | ---- | ------- | ----- | ---- |
| 05-01 | 假期 | 五一出游 | red | |
| 05-12 | 工作 | 项目评审 | | |
| 05-20 | 生活 | 朋友聚会 | blue | |
| 05-25 | 项目 | Vergil v1.0 发布 | green | https://github.com/vergil-astro/vergil-astro-theme |

:::
````

::::

- `month`：打开时显示的月份，格式 `YYYY-MM`，不写就是当前月份
- 日程写成表格，表头必须是英文列名，每列都可以省略：
  - `date`：日期，写 `MM-DD`、`YYYY-MM-DD`，或只写日 `D` 表示当月
  - `type`：类型，同一类型自动用同一种颜色
  - `content`：日程内容
  - `color`：指定颜色，可选 `blue`、`green`、`red`、`purple`、`yellow`、`cyan`、`orange`、`pink`
  - `link`：链接，带链接的日程显示小箭头，点击跳转
- 农历、节气、节假日、调休补班（橙色「班」）都是自动的，不用写

## OKR 目标管理（okr）

Objectives and Key Results 目标管理，带进度条追踪。

::::tabs
tab: 演示效果

:::okr{title="Q2 产品目标" period="2026年第二季度"}
## O1: 提升用户体验

优化核心流程，降低用户流失率。

| Key Result | Target | Current | Description | Status |
|------------|--------|---------|-------------|--------|
| 页面加载时间 | 2s | 1.5s | 首屏加载优化 | 正常 |
| 用户留存率 | 80% | 75% | 7日留存 | 风险 |
| NPS 评分 | 50 | 45 | 用户推荐度 | 正常 |

## O2: 拓展市场份额

进入两个新行业领域。

| Key Result | Target | Current | Description | Status |
|------------|--------|---------|-------------|--------|
| 新客户数 | 100 | 60 | 签约企业客户 | 正常 |
| 行业覆盖率 | 5 | 3 | 覆盖行业数量 | 滞后 |
:::

````

- `title` — OKR 总标题
- `period` — 周期，如「2026年第二季度」
- `## O1:`、`## O2:` — 定义 Objective（目标）
- KR 表格列：`Key Result`、`Target`、`Current`、`Description`、`Status`、`Link`
- `Status` 可选 `正常`（`ontrack`）、`风险`（`at-risk`）、`滞后`（`behind`）、`完成`（`completed`），写别的值会按「正常」显示
- 自动计算进度：每个 KR 的进度 = Current / Target × 100%

#### 英语学习计划（艾宾浩斯复习）

::::tabs

|-----------|---------------|---------------|-----------------|-------------|

| 单词 List 2 | 2026-05-25    | 词根词缀整理    | 25分钟 | doing       |

| 内容:text | 学习日期:date | 复习重点:text | 预计时长:number | 状态:status |
|-----------|---------------|---------------|-----------------|-------------|

| 单词 List 2 | 2026-05-25    | 词根词缀整理    | 25分钟 | doing       |

````

**用到的特性：**
- `views="ebbinghaus,table,board"` 艾宾浩斯 + 表格 + 看板
- `dateCol="学习日期"` 指定学习日期，自动计算 6 个复习节点（+1天、+2天、+4天、+7天、+15天、+30天）
- `steps="1,3,7,14,30,60,90"` 可自定义复习间隔（默认不指定即可）
- 节点状态：实心 = 已完成，呼吸动画 + 下箭头 = 今天该复习，空心 = 待复习
- **鼠标悬停节点自动显示表格中其他列的内容**（如"复习重点"、"预计时长"）
- 右侧百分比表示已完成复习节点占比

#### 自定义看板分组与顺序

#### 视图

| 视图 | 说明 |
|------|------|
| `board` | 看板视图，按状态分栏 |
| `list` | 列表视图，带筛选 |
| `table` | 表格视图 |
| `timeline` | 时间线视图 |
| `milestone` | 里程碑视图 |
| `progress` | 进度总览 |
| `ebbinghaus` | 艾宾浩斯遗忘曲线 |

#### 列类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `text` | 默认纯文本 | 任意文字 |
| `status` | 状态圆点（`todo`/`doing`/`done`） | `done` |
| `priority` | 优先级标签（`P0`/`P1`/`P2`） | `P0` |
| `date` | 日期，表格中带月份色条 | `2024-01-01` |
| `progress` | 进度条 | `65%` |
| `number` | 数字，自动千分位格式化，Notion 风格标签 | `4200` |
| `checkbox` | 勾选框（`true`/`false`） | `true` |
| `select` | 单选标签 | 任意文字 |
| `link` | 可点击链接 | `https://...` |

#### 状态列

状态列使用 `status` 类型，支持三个值：

- `todo` — 待办，空心圆
- `doing` — 进行中，半实心圆 + 呼吸动画
- `done` — 已完成，实心圆

#### 属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `title` | 组件标题 | `title="项目计划"` |
| `views` | 启用的视图 | `views="board,table"` |
| `default` | 默认视图 | `default="table"` |
| `groupBy` | board 分组列 | `groupBy="状态"` |
| `groupOrder` | board 自定义分组和列顺序（从左到右） | `groupOrder="待办,进行中,已完成"` |
| `filters` | table 筛选列 | `filters="状态,优先级"` |
| `dateCol` | 日期列映射 | `dateCol="截止日期"` |
| `startDate` | 范围起始列 | `startDate="开始"` |
| `endDate` | 范围结束列 | `endDate="结束"` |
| `progressCol` | 进度列映射 | `progressCol="完成度"` |
| `statusCol` | 状态列映射 | `statusCol="状态"` |
| `titleCol` | 标题列映射 | `titleCol="任务"` |
| `ownerCol` | 负责人列映射 | `ownerCol="负责人"` |
| `priorityCol` | 优先级列映射 | `priorityCol="优先级"` |
| `descCol` | 描述列映射 | `descCol="描述"` |
| `steps` | ebbinghaus 复习间隔（逗号分隔天数） | `steps="1,3,7,14,30"` |

#### 视图所需列

| 视图 | 所需列 | 说明 |
|------|--------|------|
| table | 无 | 永远可渲染 |
| list | 无 | 永远可渲染 |
| board | 无 | 永远可渲染 |
| timeline | `dateCol` 或 `startDate` 或 `endDate` | 单点或范围模式 |
| milestone | `dateCol` | 只支持单点模式 |
| progress | `progressCol` | 必须指定进度列 |
| ebbinghaus | `dateCol` | 艾宾浩斯复习计划，自动计算复习节点 |

> **关于列类型：** 视图所需列只要求列**存在**即可，**不强制要求特定类型**。例如 timeline 的 `dateCol` 用 `text` 类型也能工作（只要值能被 `new Date()` 解析）。但建议声明对应类型（如 `:date`、`:progress`）以获得更好的显示效果（月份色条、进度条等）。
