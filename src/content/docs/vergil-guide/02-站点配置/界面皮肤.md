# 界面皮肤

皮肤决定界面的形状和质感：圆角有多大、按钮长什么样、卡片靠投影还是描边、页面底下铺不铺底纹。颜色不归皮肤管，颜色永远来自[配色方案](/docs/vergil-guide/02-站点配置/配色方案/)。所以任何皮肤都能配任何一套配色，暗色模式也照常生效。

## 切换皮肤

皮肤和配色一样，访客可以自己切换：点右上角的主题图标，面板最上面一行就是皮肤，选完会记在浏览器里，换页、下次再来都保持。

站长在配置里定的是**默认皮肤**，也就是访客没选过时看到的那一个。打开 `src/data/config/identity.ts`，改 `skin` 这一项：

```ts
export const siteInfo = {
    title: 'Vergil',
    locale: 'zh-CN',
    skin: 'island',
    skins: ['island', 'brutalism'],
    // ...
};
```

`skin` 只能填已经启用的皮肤（见下一节），填了没启用的会退回 `classic`，构建时打一条警告，站点不会因此报错。

## 安装和启用

经典皮肤 `classic` 是内置的，其他皮肤都是独立的包，用法像 zsh 的插件：

1. **安装**：把皮肤目录放进站点根目录的 `skins/` 下，目录名就是皮肤名，比如 `skins/island/`
2. **启用**：在 `identity.ts` 的 `skins` 里写上名字

写了名字但目录不存在，构建时会跳过这个皮肤并提示该放到哪里。想停用一个皮肤，从 `skins` 里删掉名字就行，目录留着也没关系：没启用的皮肤，样式不会打进构建，面板上也不会出现。访客之前选过的皮肤被停用后，会自动退回默认皮肤。

本仓库自带 `skins/island/` 和 `skins/brutalism/` 两个皮肤，默认都已启用。

用 [vergil-cli](https://github.com/vergil-astro/vergil-cli) 的话，`vg skin add <owner/repo 或本地目录>` 会把安装和启用一起做完，`vg skin use <名字>` 设成默认皮肤，`vg skin remove <名字>` 停用并删除。装下来的皮肤是一份文件快照，跟着站点仓库一起提交，部署时不用再装一遍。

## 现有皮肤

| 值 | 来源 | 样子 |
|------|------|------|
| `classic` | 内置 | 经典皮肤，主题原本的样子：小圆角、轻投影、贴边的毛玻璃顶栏 |
| `island` | `skins/island/` | 治愈系海岛风：大圆角和胶囊按钮，页面铺一层波点底，顶栏变成悬浮的胶囊。列表页标题是燕尾飘带，选项卡和分页换成实心胶囊，标签变成浅色小签，代码块统一用暖深棕底，搜索弹窗的边缘带一点手工感的起伏。只有主按钮底下压一道实色台阶，按下去会陷进去，其余按钮和卡片都只用很轻的投影或描边 |
| `brutalism` | `skins/brutalism/` | 粗野皮肤，报纸风的新粗野主义：全部直角，纸面上只用 1px 黑色细框。容器（侧栏小组件、折叠、提示框）只描边，可点击的东西（卡片、按钮、代码块、悬浮按钮）再加一道不模糊的 4px 硬投影，悬停往左上抬，按下去沉进投影里。小标签、标签、按钮和表头用等宽大写，侧栏小标题是墨色实底的小方签，导航和目录的当前项是墨色实块，列表页标题是黑字加一道荧光笔似的高亮，分隔线是报纸上的双线，选项卡切换时会弹一下 |

每个皮肤都推荐一套配色，访客没选过配色时用的就是它，切皮肤时配色也跟着换；访客自己切过配色以后，再切皮肤配色就不动了。`classic` 推荐 C；`island` 推荐它自带的暖奶油（`warm-cream`，面板上显示 L），这是专门为它调的一套；`brutalism` 推荐它自带的报纸荧绿（`newsprint`，面板上显示 M），纸白底、黑字黑框，荧光绿只做大块平涂。皮肤自带的配色只要皮肤启用了，配别的皮肤也能用。海岛配别的配色也成立，比如配 C 暖墨就是暖白底加橙色胶囊和橙色飘带。

皮肤不管字体，字体仍然由[字体配置](/docs/vergil-guide/02-站点配置/字体与主题/)决定。想让海岛更接近原型，可以把西文字体换成 Nunito 这类圆体；粗野皮肤的等宽字取的是字体配置里的等宽字体。

## 写一个皮肤

皮肤就是 `skins/` 下的一个目录，里面只有一份清单、样式和说明，不需要改核心的任何代码：

```
skins/my-skin/
  skin.json      显示名、推荐配色、自带的配色
  skin.css       样式入口
  schemes/       自带的配色（可选），每套一个 CSS 文件
  README.md      说明（可选）
```

最简单的 `skin.json` 只要两行：

```json
{
    "contract": 1,
    "labels": { "zh-CN": "我的皮肤", "en": "My Skin" }
}
```

`skin.css` 里的规则都挂在 `html[data-skin="my-skin"]` 下面，这样别的皮肤完全不受影响。写好以后在 `identity.ts` 的 `skins` 里加上 `'my-skin'`，面板上就会出现它。

皮肤能动的东西分三层，完整的清单和清单字段见[皮肤与配色接口](/docs/vergil-guide/08-定制与扩展/皮肤与配色接口/)：

- **设计 token**：在皮肤的根选择器里重新定义 `--radius-*`、`--shadow-*`、`--ease-out`，全站所有 `rounded-lg`、`shadow-md` 这类工具类都会跟着变，这一层改动面最大、成本最低
- **`ui-*` 挂钩类**：组件上专门留给皮肤的抓手，比如顶栏 `ui-topbar`、按钮 `ui-btn`、侧栏小组件 `ui-panel`。导航里的当前项都带 `aria-current`，要改选中态就按这个属性匹配
- **内容指令**：指令的类名（`.md-tabs-nav`、`.md-directive-folding` 这些）本身就是公开的，大部分指令的圆角和描边读的是 `--md-radius*`、`--md-border` 这组变量，改掉它们就能一次统一

配色也可以反过来给皮肤递信息。海岛皮肤会读 `--bg-panel` 和 `--bg-dot`：前者有值时把正文栏放进一块这个颜色的圆角面板，后者指定波点底纹的颜色，暖奶油两个都提供了，其他配色不提供，海岛皮肤下就没有面板。粗野皮肤会读 `--bg-pop` 和 `--pop-text`，作为大块平涂的颜色和压在上面的字色，报纸荧绿提供了荧光绿和黑字，其他配色不提供就退回强调色。

皮肤只匹配 token、挂钩类、指令类名和接口文档里列出的 id，不要去匹配组件内部的 Tailwind 类名，那些类名随时可能因为重构而变。颜色一律从 `--text-main`、`--bg-card`、`--accent-color` 这些配色变量里取，需要派生色就用 `color-mix()` 混出来，别写死色值，否则换一套配色就对不上了。
