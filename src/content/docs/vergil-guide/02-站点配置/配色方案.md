# 配色方案

Vergil 内置 12 套配色方案，每套都有独特的视觉氛围。配色与暗色模式独立工作——先选配色，再决定是否开启暗色模式。

配色只管颜色。圆角、按钮、投影这些形状上的东西归[界面皮肤](/docs/vergil-guide/02-站点配置/界面皮肤/)管，两者可以任意组合。

## 如何切换

1. 点击网站右上角的主题切换图标
2. 在弹出的面板中选择配色方案（A-L）
3. 配色会立即生效，选择自动保存到本地

暗色模式有独立的开关，与配色方案互不干扰。你可以任意组合：

- Warm Parchment + 亮色模式 → 温暖的日间阅读
- Midnight Navy + 暗色模式 → 深夜代码写作
- Iris Violet + 暗色模式 → 优雅的夜间浏览

## 暗色模式

暗色模式不是简单的颜色反转，而是为每套配色单独校准的暗色变量。切换时：

- 背景色加深，但保持配色的色相倾向
- 文字对比度自动调整，确保可读性
- 强调色略微提亮，在暗背景下依然醒目

## 自定义配色（高级）

如果你想添加第 13 套配色，需要改几处源码：

1. 在 `src/styles/base/theme.css` 里新增 `html[data-theme="M"]` 和 `html[data-theme="M"].dark` 两个变量块，定义 `--text-main`、`--bg-main`、`--accent-color` 等语义变量。暗色不会自动推导，要自己写一份
2. 在 `src/components/ui/ThemeToggle.astro` 的 `schemes` 列表里加一项，面板上才会出现这个色点
3. 在 `src/scripts/theme-toggle.js` 的 `SCHEMES` 和 `SCHEME_COLORS` 里加上 `M`
4. 在 `src/i18n/` 各语言文件的 `theme.schemes` 里给它起个名字

:::callout{type="tip"}
如果不确定选哪套，建议先用默认的 **C Warm Ink**，它经过最多场景测试，兼容性最好。
:::
