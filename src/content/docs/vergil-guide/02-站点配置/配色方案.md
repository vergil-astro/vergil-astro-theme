# 配色方案

Vergil 内置了一组配色方案，每套都有独特的视觉氛围；皮肤和单独的配色包还可以再带来新的配色。配色与暗色模式独立工作——先选配色，再决定是否开启暗色模式。

配色只管颜色。圆角、按钮、投影这些形状上的东西归[界面皮肤](/docs/vergil-guide/02-站点配置/界面皮肤/)管，两者可以任意组合。

| 面板上 | 配色 ID | 名称 | 来自 | 说明 |
|------|------|------|------|------|
| J | `cream-coral` | Cream Coral 奶油珊瑚 | 海岛皮肤 | 明快、柔和，适合生活、手账、随笔 |

## 如何切换

1. 点击网站右上角的主题切换图标
2. 在弹出的面板中选择配色方案
3. 配色会立即生效，选择自动保存到本地

访客没选过配色时，用的是当前[界面皮肤](/docs/vergil-guide/02-站点配置/界面皮肤/)推荐的那套：经典皮肤是 C，海岛皮肤是暖奶油，粗野皮肤是报纸荧绿，访客切皮肤时配色也跟着换。皮肤推荐哪套写在皮肤目录的 `skin.json` 里（`recommendedScheme`），经典皮肤的写在 `src/appearance/builtin.mjs`。访客之前选过的配色如果被停用了，会自动退回当前皮肤推荐的那套。

暗色模式有独立的开关，与配色方案互不干扰。你可以任意组合：

- Warm Parchment + 亮色模式 → 温暖的日间阅读
- Midnight Navy + 暗色模式 → 深夜代码写作
- Iris Violet + 暗色模式 → 优雅的夜间浏览

## 暗色模式

暗色模式不是简单的颜色反转，而是为每套配色单独校准的暗色变量。切换时：

- 背景色加深，但保持配色的色相倾向
- 文字对比度自动调整，确保可读性
- 强调色略微提亮，在暗背景下依然醒目

## 添加配色

新配色做成一个配色包，不用改核心代码，用法和皮肤一样：

1. 在站点根目录建 `schemes/<配色名>/`，比如 `schemes/ocean/`
2. 写一份 `scheme.json`，给面板提供显示名和色点颜色：

   ```json
   { "contract": 1, "short": "O", "labels": { "zh-CN": "海洋", "en": "Ocean" }, "swatch": "#0066cc" }
   ```

3. 写 `scheme.css`，在 `html[data-theme="ocean"]` 和 `html[data-theme="ocean"].dark` 两个块里定义 `--text-main`、`--bg-main`、`--accent-color` 等变量。暗色不会自动推导，要自己写一份
4. 在 `src/data/config/identity.ts` 的 `schemes` 里加上 `'ocean'`

如果配色是专门为某个皮肤调的，也可以直接放进那个皮肤的 `schemes/` 目录，在它的 `skin.json` 里登记。必填的变量、可选的变量和清单字段见[皮肤与配色接口](/docs/vergil-guide/08-定制与扩展/皮肤与配色接口/)。

:::callout{type="tip"}
如果不确定选哪套，建议先用默认的 **C Warm Ink**，它经过最多场景测试，兼容性最好。
:::
