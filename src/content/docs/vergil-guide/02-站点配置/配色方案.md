# 配色方案

配色只管颜色，圆角、按钮、投影这些形状上的东西归[界面皮肤](/docs/vergil-guide/02-站点配置/界面皮肤/)管。每个皮肤带着自己的几套配色，访客在一个皮肤下只能选它自己的：经典皮肤用内置的十套，其他皮肤用各自带的。配色与暗色模式独立工作——先选配色，再决定是否开启暗色模式。

## 内置配色

| 代号 | 名称 | 主色调 | 氛围 | 适用场景 |
|------|------|--------|------|---------|

| C | Warm Ink | 暖墨 | 素雅、克制 | 通用博客（经典皮肤的默认配色） |
| D | Creamy Rose | 奶油玫瑰 | 柔和、浪漫 | 生活、摄影、设计 |
| E | Butter Amber | 黄油琥珀 | 温暖、复古 | 旅行、美食、怀旧 |
| F | Sage Mint | 鼠尾草薄荷 | 清新、自然 | 户外、植物、健康 |
| G | Iris Violet | 鸢尾紫 | 优雅、神秘 | 艺术、音乐、创意 |
| H | Midnight Navy | 午夜海军蓝 | 深邃、专业 | 编程、商业、科技 |

## 皮肤自带的配色

这几套是专门为某个皮肤调的，跟着皮肤一起安装和启用，只在那个皮肤下能选。

| 面板上 | 配色 ID | 名称 | 来自 | 说明 |
|------|------|------|------|------|
| J | `cream-coral` | Cream Coral 奶油珊瑚 | 海岛皮肤 | 明快、柔和，适合生活、手账、随笔 |
| L | `warm-cream` | Warm Cream 暖奶油 | 海岛皮肤 | 温暖、治愈，海岛皮肤的默认配色；正文会放进奶油色面板 |
| M | `newsprint` | Newsprint 报纸荧绿 | 粗野皮肤 | 利落、醒目，粗野皮肤唯一的配色：纸白底、黑字黑框，荧光绿只做大块平涂；文字不用灰，正文链接带下划线 |

## 如何切换

1. 点击网站右上角的主题切换图标
2. 在弹出的面板中选择配色方案，面板上只列出当前皮肤的配色
3. 配色会立即生效，选择自动保存到本地

访客没选过配色时，用的是当前[界面皮肤](/docs/vergil-guide/02-站点配置/界面皮肤/)的默认配色：经典皮肤是 C，海岛皮肤是暖奶油，粗野皮肤是报纸荧绿。切换皮肤时，配色也换成新皮肤的默认配色。默认配色写在皮肤目录的 `skin.json` 里（`recommendedScheme`），经典皮肤的写在 `src/appearance/builtin.mjs`。访客之前选过的配色如果被停用了，会自动退回当前皮肤的默认配色。

暗色模式有独立的开关，与配色方案互不干扰。你可以任意组合：

- Warm Parchment + 亮色模式 → 温暖的日间阅读
- Midnight Navy + 暗色模式 → 深夜代码写作
- Iris Violet + 暗色模式 → 优雅的夜间浏览

## 暗色模式

暗色模式不是简单的颜色反转，而是为每套配色单独校准的暗色变量。切换时：

- 背景色加深，但保持配色的色相倾向
- 文字对比度自动调整，确保可读性
- 强调色略微提亮，在暗背景下依然醒目

## 添加配色

内置配色之外的配色只能由皮肤自带，没有单独的配色包。要加一套新配色，就把它放进某个皮肤，它会出现在这个皮肤的配色里，不用改核心代码：

1. 在皮肤目录的 `schemes/` 下加一个 `<配色 ID>.css`，比如 `skins/island/schemes/ocean.css`，在 `html[data-theme="ocean"]` 和 `html[data-theme="ocean"].dark` 两个块里定义 `--text-main`、`--bg-main`、`--accent-color` 等变量。暗色不会自动推导，要自己写一份
2. 在这个皮肤的 `skin.json` 的 `schemes` 里登记，给面板提供显示名和色点颜色：

   ```json
   { "id": "ocean", "short": "O", "labels": { "zh-CN": "海洋", "en": "Ocean" }, "swatch": "#0066cc" }
   ```

必填的变量、可选的变量和清单字段见[皮肤与配色接口](/docs/vergil-guide/08-定制与扩展/皮肤与配色接口/)。

:::callout{type="tip"}
用经典皮肤又不确定选哪套时，建议先用默认的 **C Warm Ink**，它经过最多场景测试，兼容性最好。
:::
