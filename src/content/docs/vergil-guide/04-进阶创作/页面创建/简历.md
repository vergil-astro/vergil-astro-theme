# 简历配置

Vergil 内置简历视图，可将 Markdown 简历渲染为专业的在线履历页面。

## 文件位置

简历存放在 `src/content/resume/` 目录下，使用 Markdown 格式（`.md`）。

## 文件格式

```markdown
---
title: 简历
name: 张三
headline: 高级前端工程师
avatar: /assets/site/avatar.jpg
contact:
  email: zhangsan@example.com
  phone: 138****8888
  location: 北京
  github: https://github.com/zhangsan
  website: https://example.com
blur: [phone]
---

## 个人简介

5 年前端开发经验，专注于 React 生态...

## 工作经历

### 某某公司 · 高级前端工程师

*2022.03 - 至今*

- 负责公司核心产品的前端架构设计
- 带领 5 人团队完成项目重构

## 教育背景

### 某某大学 · 计算机科学

*2015.09 - 2019.06*

## 技能

- React / Vue / TypeScript
- Node.js / Python
- Docker / CI/CD
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `title` | 是 | 页面标题 |
| `name` | 是 | 姓名 |
| `headline` | 否 | 姓名下面的一行，比如职位、方向，不写就不显示 |
| `avatar` | 否 | 头像路径，打印时不显示 |
| `contact` | 否 | 联系方式 |
| `blur` | 否 | 先模糊显示、点了才显示的信息，见[模糊显示](#模糊显示) |
| `preview` | 否 | 加密后允许没有密码的访客预览删减版，见[预览](#预览) |
| `password` | 否 | 简历密码，写了就加密，见[加密与分享](#加密与分享) |

### contact 子字段

| 字段 | 说明 |
|------|------|
| `email` | 邮箱 |
| `phone` | 电话 |
| `location` | 所在城市 |
| `github` | GitHub 主页地址 |
| `website` | 个人网站 |

网址显示时会去掉 `https://`，比如 `https://github.com/zhangsan` 显示成 `github.com/zhangsan`。

### 经历的写法

每段经历或每个项目用 `###` 开头，紧跟一行只有斜体的时间：

```markdown
### 某某公司 · 高级前端工程师

*2022.03 - 至今*
```

宽屏和打印时，时间会排到标题右边；手机上排在标题下面。时间那一行要单独成段，并且整行都是斜体，否则会当成普通段落。

## 模糊显示

电话、邮箱这类信息不想让人一眼看到，可以列在 `blur` 里，页面上先模糊显示，访客点一下才看得清：

```markdown
---
name: 张三
contact:
  email: zhangsan@example.com
  phone: 138 0000 0000
blur: [phone, email]
---
```

可以列的有 `name`、`headline`、`email`、`phone`、`location`、`github`、`website`。

- 模糊的程度和 `:blur[]` 指令一样，但鼠标悬停不会显示，只有点了才显示
- 电话、邮箱这类链接，没点开之前点一下只会显示内容，不会直接拨号或发邮件；显示以后再点才会
- 打印时一律清楚显示，打出来的简历能直接联系到人
- 这只是挡一下随便扫过的目光，内容还在页面里。真要藏起来，用下面的[加密](#加密与分享)

## 页面布局

简历是居中的一张「纸」，宽屏分两栏：左栏是头像、姓名、`headline` 和联系方式，往下滚动时固定不动；右栏是正文。手机上左栏排在正文上方。顶部一条细工具栏：左边返回站点，中间是各个分组的目录（手机上不显示），右边是分享、打印和外观切换。

简历统一用无衬线字体，不跟博客正文的字体走。想换字体，在站点样式里设置 `--resume-font`。

## 访问路径

简历页面访问地址为 `/views/resume/`。

## 加密与分享

简历里有电话、邮箱，不想让搜索引擎和随手点进来的人看到，可以给简历加一个密码：

```markdown
---
title: 个人简历
name: 张三
password: mima123
---
```

加了以后，页面里只有密文，姓名、联系方式、目录和正文都要用密码解开才能看到。锁着的时候页面上只有一个密码框，顶部工具栏、目录和纸面都不显示。

密码只在锁屏上手动输入时用。分享出去的链接里放的是由密码算出来的一串口令，看不出密码是什么：

| 打开的地址 | 看到什么 |
|------|------|
| `/views/resume/` | 锁屏，输入密码后显示简历 |
| `/views/resume/#Xk3vQ9…`（分享链接） | 直接显示简历，不用输密码 |
| `/views/resume/#过期的口令` | 锁屏，提示链接已失效，可以再手动输入密码 |

口令只和密码有关，密码不变，每次重新部署链接都不变。`#` 后面的部分不会发给服务器，也不会被访问统计记下来。

### 预览

加了密码以后，还可以让没有密码的访客先看一份删减版，公司、学校和联系方式藏起来，其余照常显示：

```markdown
---
password: mima123
preview:
  redact: [工作经历, 教育背景]
  hide: [email, phone]
---
```

- 锁屏上会多一个「预览」按钮，点了进入预览，页面顶部提示哪些内容被隐藏，旁边可以回去输入密码
- `redact` 写分组的名字（`##` 标题的文字），这些分组里每段经历的标题（`###`，比如「某某公司 · 职位」）换成黑色遮挡条，展开不了
- `hide` 里的联系方式换成模糊的占位符，可以写 `email`、`phone`、`location`、`github`、`website`，不写默认是 `[email, phone]`
- 预览时点遮挡条或模糊的联系方式，会回到输入密码页并提示输入密码
- 预览时不能分享、打印
- 删减版是构建时生成的，被遮住的文字直接删掉了，不在页面里，查看源码也看不到；但没被遮住的部分是明文放在页面里的

### 分享给别人

解锁后，顶部工具栏右边的分享按钮分享出去的是带口令的链接，对方打开就能直接看到简历：

- 手机上调起系统分享面板，可以直接发到聊天软件
- 电脑上把链接复制到剪贴板，同时把链接显示出来
- 浏览器不让复制时（比如部分 App 的内置浏览器），链接也会显示出来，可以手动复制

没设密码的简历也有分享按钮，分享的是普通链接。

### 换密码

改掉 `password` 重新部署，之前发出去的链接就打不开了，会停在锁屏。

同一个浏览器标签页里解锁过一次，在站内跳到别的页面再回来不用重新输入；关掉标签页以后要重新解锁。

### 能挡住什么

分享链接相当于钥匙，这套加密不是登录，只用来挡住搜索引擎和随手点进来的人：

- 拿到链接的人都能看，也能继续转发，只是看不到密码本身
- 锁屏上只写「内容已加密」，看不出是简历；但页面标题（`title`）和地址 `/views/resume/` 不加密，标题会显示在浏览器标签上，别把姓名写进去
- 密码和简历原文都写在 `src/content/resume/` 里，仓库公开的话，任何人都能在源文件里看到。要加密，仓库得是私有的
- 页面里的密文可以被下载下来反复猜密码，密码太短挡不住，建议至少 8 位，别用常见的词
- 浏览器只在 https 或者本机（`localhost`）下允许解密。用局域网 IP 打开开发服务器时，锁屏会提示无法解密

## 打印

点顶部工具栏的打印按钮，或者按 `Ctrl+P`（`Cmd+P`），可以打印或存成 PDF。打印时：

- 按 A4 排版，保留屏幕上的两栏设计：左栏的底色、头像、姓名和联系方式，右栏正文和强调色竖条都会打出来；顶部工具栏不打印
- 暗色模式下打印，会按当前配色的亮色版本输出；链接不显示颜色和下划线
- 浏览器打印设置里要勾选「背景图形」，左栏底色才会打出来
- 每页底部有页脚：左边是姓名和简历标题，右边是「Generated by Vergil Astro Theme」和页码（需要较新的 Chrome）。浏览器自带的页眉页脚会打出网址和日期，打印时取消勾选「页眉和页脚」即可
- 经历的标题不会和下面的内容分在两页，每条要点也不会从中间断开

## 在导航中添加入口

在 `src/data/config/nav.ts` 中添加简历链接：

```typescript
headerNavLinks: [
    {
        label: '页面',
        children: [
            { label: '主页', href: '/' },
            { label: '简历', href: '/views/resume/' }
        ]
    }
]
```
