# 手绘标注

用 `:ann` 给正文里的词画上手绘箭头和批注，像读书时在页边随手写下的笔记。下面拿王维的《山居秋暝》做个示范。

::::tabs
tab: 演示效果

:ann[空山]{note="雨后格外静" direction="top-right" color="green"}新雨后，天气:ann[晚来秋]{note="傍晚才觉出秋凉" direction="top-right" color="amber"}\
明月松间照，清泉:ann[石上流]{note="听得见水声" direction="right" color="blue"}\
:ann[竹喧]{color="rainbow"}归浣女，莲动:ann[下渔舟]{note="渔船穿过莲叶" direction="right" color="purple"}\
随意:ann[春芳歇]{note="春花谢了也无妨" color="red"}，王孙:ann[自可留]{note="尽可留下来" direction="bottom-right"}

tab: 示例代码

`````markdown
:ann[空山]{note="雨后格外静" direction="top-right" color="green"}新雨后，天气:ann[晚来秋]{note="傍晚才觉出秋凉" direction="top-right" color="amber"}\
明月松间照，清泉:ann[石上流]{note="听得见水声" direction="right" color="blue"}\
:ann[竹喧]{color="rainbow"}归浣女，莲动:ann[下渔舟]{note="渔船穿过莲叶" direction="right" color="purple"}\
随意:ann[春芳歇]{note="春花谢了也无妨" color="red"}，王孙:ann[自可留]{note="尽可留下来" direction="bottom-right"}
`````

::::

| 参数 | 作用 | 可选值 | 默认 |
|------|------|--------|------|
| `note` | 批注文字，不写就只留底色（比如上面的「竹喧」） | 任意文字 | 无 |
| `direction` | 批注在被标注文字的哪个方位 | `top` `top-right` `right` `bottom-right` `bottom` `bottom-left` `left` `top-left` | `bottom` |
| `color` | 箭头、批注和底色的颜色 | `amber` `blue` `green` `red` `purple` `rainbow` | 暖灰 |

用了标注的段落上下会自动留出空白，给批注腾地方。批注挤在一起时，换个方向，或者像上面这样让上一行往上标、下一行往下标，中间的行往右标。
