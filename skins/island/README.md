# 海岛皮肤（island）

Vergil 的治愈系海岛风皮肤：大圆角和胶囊按钮，页面铺一层波点底，顶栏变成悬浮的胶囊。列表页标题是燕尾飘带，选项卡和分页换成实心胶囊，代码块统一用暖深棕底，搜索弹窗的边缘带一点手工感的起伏。

视觉语言参考 GitHub 上的动森风格项目 animal-island-ui 的设计规范，没有拷贝它的代码、字体和插画。

## 安装

在站点目录里运行 `vg skin add island`，安装和启用一步完成，`vg skin use island` 设成默认皮肤。

不用 vg 的话，把这个目录复制到站点根目录的 `skins/island/`，再在 `src/data/config/identity.ts` 里启用：

```ts
skins: ['island'],
skin: 'island',   // 想让访客默认看到海岛皮肤就加这一行
```

## 自带配色

| 面板上 | 配色 ID | 名称 | 说明 |
|------|------|------|------|
| L | `warm-cream` | 暖奶油 | 推荐配色。配海岛皮肤时正文会放进一块奶油色面板 |
| J | `cream-coral` | 奶油珊瑚 | 香草奶油底配珊瑚色，同属奶油系但不偏棕 |

两套都提供了 `--bg-panel` 和 `--bg-dot`，海岛皮肤会用它们画正文面板和波点底纹。

## 文件

```
skin.json            清单
skin.css             样式入口
styles/              按区域拆开的样式：基础、导航、正文、浮层、内容指令
schemes/             自带的两套配色
```

外观接口版本：1。格式和可以依赖的挂钩见 Vergil 文档「皮肤与配色接口」。
